# Vice Verano: Afterglow

Vice Verano is an original, browser-playable open-world crime game about Rico Salaz, an ex-wheelman trying to make a clean start in a hot coastal city. Coral Row, Harborline, Miraflores, Little Sombra and the Causeway are generated entirely from code with pastel facades, traffic, pedestrians, palms, shops and a working road grid.

## Play

Open `game/index.html` through any static server. Click **New Game**, then use WASD to walk or drive, Shift to sprint, Space to jump or handbrake, and F to enter or leave a vehicle. Right mouse aims, left mouse fires, M opens Nadia’s phone line, and Escape pauses. Stealing cars, shooting and collisions raise the wanted level; escape the search radius to cool it down. The six-story mission chain advances through theft, delivery, collections, a chase, a dock shootout and a four-star escape. Continue restores your local save.

All models, effects, music and sound effects are synthesized in the game. There are no network assets or borrowed art, music, names or story material.

## Local run

From the repository root:

```sh
node serve.ts --port 8081
```

Then browse to `http://localhost:8081/`.
